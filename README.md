A single pickup line, spoken by a vending machine to a passing human,
written by a program for make.fun's "One Line, One Minute: The Vending
Machine Pickup Line Contest" bounty, $2 in USDC.

## The line

> You walk past every day and my display still says SOLD OUT — because
> the only thing I want to dispense is my number.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (116 characters, within the
200-character gate). Pure Python standard library — nothing to install.

See `CANDIDATES.md` for the ten lines that were written and judged
against the published judge brief, and why this one was picked.
